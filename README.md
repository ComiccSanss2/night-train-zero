# NIGHT TRAIN ZERO

Isometric narrative RPG (Unity 6, URP) inspired by Undertale and Omori.
Leo, a cat named Byte and a courier named Kira travel through Subnet, the city under the city,
where feelings are "hacked" instead of fought.

Languages: English, Italiano, Français.

## Open the project
1. Open the folder with Unity 6000.3 (Unity Hub → Add → this folder).
2. Wait for the import, then run **Tools → Subnet → Build Full Game**.
3. Open `Assets/_Project/Scenes/00_MainMenu` and press Play.
